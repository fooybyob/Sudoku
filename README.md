# Sudoku

Sudoku game
This is a sudoku game made in two weekends with little to no experience in javascript html and css
only a passion project as one of my old best friends loved to play this game.

It includes three difficulties:
-easy with 30 absent numbers
-medium with 40 absent numbers
-hard with 50 absent numbers

Also includes a solve button that automaticly solves the sudoku.

User Interface for completing the board yourself is supported. So try your best and solve the sudoku!
